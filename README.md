Data Science & Python Practice Portfolio

Welcome to my personal practice repository! This collection documents my hands-on learning journey in Python programming, Data Analysis, Web Scraping, and Machine Learning.
The projects and exercises here focus on transforming raw data into actionable insights, automating workflows, and building predictive models using real-world and benchmark datasets.

🛠️ Tech Stack & Libraries
Core Language: Python 3
Data Manipulation & Analysis: Pandas, NumPy
Data Visualization: Matplotlib, Seaborn
Machine Learning: Scikit-Learn
Web Scraping & Automation: BeautifulSoup / Requests, OpenPyXL / Excel export, Automated Emailing (smtplib)
Environment: Jupyter Notebooks, Python Scripts (.py)


📂 Repository Structure
1. 🤖 Machine Learning (MachineLearning/)

End-to-end supervised and unsupervised machine learning workflows, including Exploratory Data Analysis (EDA), feature engineering, model training, and hyperparameter/performance evaluation:

Linear Regression (Linear Regression Project.ipynb): Predicting customer yearly spending based on E-commerce behavioral metrics (app vs. website usage, session length).

Logistic Regression (Logistic Regression/): Classification model predicting ad click-through behavior using user demographics and internet usage data (advertising.csv).

K-Nearest Neighbors (KNN/): Implementing KNN classification with feature scaling and optimal $K$-value selection using the elbow method.

Decision Trees & Random Forests (Decision Trees and Random Forest Project/): Predicting borrower repayment likelihood on LendingClub loan data (loan_data.csv), comparing single tree vs. ensemble performance.

Support Vector Machines (Support Vector Machine Project/): Classification modeling with kernel methods and grid search tuning (GridSearchCV).

K-Means Clustering (K_Means Clustering Project/): Unsupervised learning to cluster universities into public vs. private groups based on institutional metrics (College_Data).


2. 📊 Data Manipulation & Analysis (NumPy and Pandas/)

Structured exercises mastering data wrangling, cleaning, and statistical aggregation across diverse datasets:

Filtering & Sorting (pandas - Filtering & Sorting/): Querying and ranking subsets of data (Chipotle orders, Euro 2012 team statistics, Fictional Army datasets).

Applying Functions (Pandas - Apply/): Custom row/column transformations using .apply() and lambda functions on US Crime Rates (1960–2014) and Students Alcohol Consumption datasets.

Merging & Joining (pandas - Merge/): Combining relational tables, handling missing values, and concatenating datasets (Auto MPG, Housing Market, Fictitious Names).

Statistical Aggregation (pandas - Stats/): Grouping, summarizing, and analyzing demographic trends using US Baby Names.

Initial Data Exploration (Pandas - knowing your data/): Inspecting data types, distributions, and summary statistics (Occupation, Chipotle).


3. 🌐 Web Scraping & Workflow Automation

Practical Python scripts designed to automate data collection and reporting tasks:

E-Commerce Price Scraper (web_scrap/): Extracts product information and pricing from Sklavenitis online supermarket and structures the output into a clean Excel report (sklavenitis_products.xlsx).

Automated Price Monitoring & Email Reporting (web_scrap_and_email_excel_file/): An end-to-end automation pipeline that scrapes product prices, exports the results to Excel (prices_products.xlsx), and automatically emails the report.


4. 🧩 Core Python Fundamentals

Foundational algorithmic and file-handling scripts:

Prime Factorization (prime_factorization/): Mathematical utility to decompose integers into their prime factors.

Text File Word Counter (count_words/): Script for parsing text files and computing word frequency counts.
